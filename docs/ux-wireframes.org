* Delib-Flow UX Wireframes

These sketches are the canonical buffer-surface contracts for the architecture
refactor. They are intentionally text-first and terminal-friendly.

For the editable, testable main-scenario contract layer, see
[[file:ui-scenario-contracts.org][ui-scenario-contracts.org]].

* Main cockpit

#+begin_example
* Now
  Current loop state and immediate recommendation.

* Current result
  Latest stage outcome.

* Filing preview
  Destination appears before any file action.

* Next actions
  1. Local action
  2. Secondary action

* Current context
  Retrieved and retained supporting material.

* Details
  Stage history, diagnostics, and expanded notes.
#+end_example
