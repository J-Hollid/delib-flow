* Delib-Flow UX Wireframes

These sketches are the canonical buffer-surface contracts for the architecture
refactor. They are intentionally text-first and terminal-friendly.

For the editable, testable main-scenario contract layer, see
[[file:ui-scenario-contracts.org][ui-scenario-contracts.org]]. For the
phase-travel overview diagram, see
[[file:stage-flow-overview.org][stage-flow-overview.org]].

* Main cockpit

#+begin_example
* Now
  Current phase, goal, readiness, and block state.

* Recommended
  One recommended action, nearby alternatives, and grouped action roles.

* Progress
  Checklist, queue hub, selected-item summary, and detour return.

* Current result
  Latest stage outcome.

* Details
  Phase-relevant detail view plus stage history and audit diagnostics.

Operator controls:
- `z` toggles narrow-screen focus mode.
- `Y` toggles whether debug-only cockpit actions are visible.
#+end_example
