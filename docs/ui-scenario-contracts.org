#+title: delib-flow UI scenario contracts

This document is the executable UI contract for the phase-travel
operator surfaces in =delib-flow=.

Each top-level contract binds one deterministic debug checkpoint to one
surface and asserts the user-facing phase layout, visible action
groups, and surface transitions.

:PROPERTIES:
:SCENARIO_ID: alpha-followup
:CHECKPOINT: source
:SURFACE: cockpit
:TITLE: Source review cockpit
:USE_CASE: scenario-1
:END:

|     1 | Now             | yes      |
|     2 | Recommended     | yes      |
|     3 | Progress        | yes      |
|     4 | Current result  | yes      |
|     5 | Details         | yes      |
