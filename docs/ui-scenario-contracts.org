#+title: delib-flow UI scenario contracts

This document is the executable UI contract for the main =delib-flow=
operator scenarios.

Use it for the middle layer between:

- [[file:ux-wireframes.org][ux-wireframes.org]] as the lightweight surface sketch
- [[file:operator-use-cases.org][operator-use-cases.org]] as the narrative manual walkthrough
- render and UI tests as the automated enforcement layer

Each top-level contract binds one UI surface to one deterministic debug
scenario checkpoint.
