phases while keeping the underlying stage engine and audit trail
unchanged.

"Selected item" --> "Reference context" : needs more support
"Selected item" --> "Project context" : wrong project context
"Selected item" --> "Selected item" : wrong filing target

note right of "Cloud reroute"
Travel state remembers:
- origin phase
- origin action/stage
- reroute reason
- return surface/anchor
end note

note right of "Selected item"
The filing workspace is the primary
authoring surface once an item is selected.
end note
